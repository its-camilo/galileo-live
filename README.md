# Galileo Live

**A physics lab that fits in your pocket.** Galileo Live is a voice-guided physics lab for students and hobbyists. The phone records the experiment, Meta's models find and follow the object, and the app returns the measured acceleration, its error against theory, plots, and a LaTeX lab report.

- Live app: https://galileo-live.vercel.app
- Hackathon: Meta Global AI Developer Hackathon, Indie Developer Track, *Push the Frontier*
- Built entirely during the event (first commit: 2026-10-27). No prior code was reused.

## What it does

1. **Choose an experiment by voice or from the catalog.** For example, a cart on a ramp (uniform acceleration) or free fall. *Muse Voice Transcribe* turns speech into text, and *Muse Spark* acts as the lab partner: it picks the experiment, explains the setup, and checks the live camera frame.
2. **Calibrate the scale.** Take a photo, tap the two ends of a ruler, and enter its real length to convert pixels to meters.
3. **Record up to 10 seconds.** Type the object's name in any language. Muse Spark turns it into a short English concept for SAM. *SAM 3.1* tracks every matching object through the clip. Galileo keeps only the object that moves and ignores static look-alikes. If SAM finds nothing, Galileo tries a more general name, and then names that Muse Spark suggests after looking at a frame of the clip.
4. **Get physics, not just pixels.** Galileo fits `x(t) = x0 + v0·t + ½·a·t²` to the smoothed track. It reports `a` (or `g`) and the error against `g·sinθ` or 9.81 m/s², and plots x(t), v(t) and a(t).
5. **One-tap lab report.** A LaTeX PDF with data, plots, analysis and a setup diagram generated by *Muse Image*. It is stored privately in Vercel Blob, and every past report appears under *My reports*.

The clip is deleted on the server and in Meta's file store as soon as SAM finishes. Only the measured data is kept.

## Meta models used

| Model | Role |
|---|---|
| Muse Spark 1.3 | Lab-partner agent; live-frame checks; translating object names into SAM concepts; suggesting alternative concepts from a frame |
| SAM 3.1 (Responses API, video) | Concept-prompted tracking of the object across every frame (`one_bit` masks; only the boxes are kept) |
| Muse Voice Transcribe | Push-to-talk speech-to-text (English and Spanish) |
| Muse Image 1.0 | Experiment setup diagram in the report |

## Architecture

| Layer | Tech | Runs on |
|---|---|---|
| Client | Next.js PWA (camera, MediaRecorder, push-to-talk, speech synthesis), EN/ES | Phone browser |
| Web + auth | Next.js App Router, Auth.js (Google), mints a short-lived HS256 token for the API | Vercel |
| API | FastAPI, ffmpeg, numpy/scipy, matplotlib, Jinja2 + tectonic (LaTeX) | Render (Docker) |
| Data | PostgreSQL (history), private Vercel Blob (PDFs) | Neon / Vercel |

Flow: phone → Vercel (Google login, 5-minute token) → FastAPI → Meta Model API → result and PDF → Blob.

### Measurement pipeline (`api/app/routes.py`, `api/app/meta.py`, `api/app/measure.py`)

- ffmpeg normalizes the clip to constant 30 fps H.264 at 960 px wide (2 threads, small memory footprint).
- The clip is uploaded to the Meta Files API. SAM 3.1 runs with a concept prompt, and the stream is parsed line by line. Mask payloads are dropped on arrival, and only per-object boxes are kept.
- `pick_moving_track` groups detections by object id and keeps the object whose centroid moves at least 2.5 % of the frame (10th to 90th percentile range).
- Pixels are converted to meters with the calibration, smoothed with Savitzky–Golay, and fit by least squares.

### Robustness on a free 512 MB instance

- Heavy work (ffmpeg, SAM, LaTeX) runs in a worker thread, so `/health` keeps answering. Only one heavy job runs at a time.
- Uploads are streamed to disk in 1 MB chunks. Files are deleted right after use, followed by `gc` and `malloc_trim`, with `MALLOC_ARENA_MAX=2`.
- CORS is the outermost middleware, so error responses still reach the browser.

## Security and privacy

- The API only accepts HS256 tokens issued by the web app (`aud=galileo-vps`, short lifetime).
- Per-IP rate limits and per-user daily quotas protect the Meta credits.
- Trusted hosts, a strict CORS allow-list, OpenAPI docs disabled, and security headers.
- Videos are never stored, and PDFs are private (downloaded through the API).

## Run locally

```bash
cd api
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
DATABASE_URL=postgresql://... APP_JWT_SECRET=dev MODEL_API_KEY=... uvicorn app.main:app --port 8000
pytest          # needs a local Postgres (TEST_DATABASE_URL)
```

Requires `ffmpeg`, `ffprobe` and `tectonic` on the PATH.

```bash
cd web
cp .env.example .env.local   # fill in the secrets
npm install && npm run dev
```

## Deploy

- **API:** Render Blueprint (`render.yaml`, `api/Dockerfile`). Secrets: `APP_JWT_SECRET`, `MODEL_API_KEY`, `BLOB_READ_WRITE_TOKEN`, `DATABASE_URL`, `ALLOWED_HOSTS`. An UptimeRobot keyword monitor on `/health` keeps it awake.
- **Web:** Vercel, root `web`. Variables: `AUTH_GOOGLE_ID`, `AUTH_GOOGLE_SECRET`, `AUTH_SECRET`, `APP_JWT_SECRET`, `APP_JWT_AUDIENCE`, `NEXT_PUBLIC_API_URL`.
